# Facebook Clone (Front-end Practice)

A simple front-end clone / practice project inspired by social media UI layouts.

## About

This repository contains early HTML & CSS learning exercises focused on recreating common social media interface patterns.  
It is a practice project for building layout skills, flexbox/grid usage, and visual design fundamentals.

## Features

- Basic social media style layout
- Custom CSS styling
- Learning-focused structure

## Tech Stack

- HTML5
- CSS3

## Project Structure

```
html learning/
├── index.html
└── style.css
```

## How to Run

```bash
git clone https://github.com/ankitsapkota2002-boop/facebook-clone-.git
cd "facebook-clone-/html learning"
# Open index.html in a browser
```
